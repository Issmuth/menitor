# 7. Beginners and bootcamp grads are the primary users

Date: 2026-11-04 · Status: accepted

## Context

Task size, explanation depth and test projects all need one default target. Experienced developers learning a new stack want speed instead.

## Decision

Defaults are tuned for self-taught beginners and bootcamp grads. Experienced developers are served through the fast level and focus areas: the new stack is the focus area, and the basics are delegated.

## Consequences

- A warm-up of 10 minutes or less, or an existing repo, sets the level. The learner never rates themselves.
- Guided tasks run 20 to 45 minutes, standard 45 to 90, and fast 1.5 to 3 hours.
