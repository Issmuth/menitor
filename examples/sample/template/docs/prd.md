# Recipe box — Product requirements

## Problem

I keep recipes in screenshots, notes and open tabs. When I want to cook, I can never find the one I need.

## Users

Home cooks who save recipes from many places and want them in one list.

## Must-have features

### Home

The home page shows the app name and the list of recipes.

### Recipe list

The app serves the recipes as JSON, so the page and later tools can use them.

### Health check

The host can check that the app is up.

## Out of scope

Accounts, photos and search. They come after the first version.

## Success

The app is deployed, and I use it for a week instead of my screenshots.
