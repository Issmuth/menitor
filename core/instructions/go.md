# Show the current task

Pick up exactly where the learner left off. A fresh session knows nothing else, so Menitor's files and git rebuild it.

Run `{{go}}`. It opens the task window and prints the card, with only the doc section it links to. It shows what changed in git since the task started, then says what to do next. Do that, and don't read other docs unless the task needs them. If it says setup isn't done, point the learner to {{cmd:start}}.

When it says to wait for their press, call {{wait}}, so it reaches you at once.
